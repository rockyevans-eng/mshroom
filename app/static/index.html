Structure: Message → Segment → Field → Component → Subcomponent (a field can also repeat)

Segment | Field ^ Component & Subcomponent    Repetition ~

CharSeparatesExample
|FieldsPID|1||12345^^^HOSP^MR||DOE^JANE
~Repetitions of a field555-1234~555-9876
^ComponentsDOE^JANE^Q (family^given^middle)
&SubcomponentsA&B within one component
\Escape character\F\ = a literal |
CRSegments (0x0D)one segment per line

The separators are declared in the message itself: MSH-1 is | and MSH-2 is ^~\&.

Reference notation (as MSHroom shows it): PID-5.1.2 = segment PID, field 5, component 1, subcomponent 2. Field repetition: PID-3[2]. Repeated segment: OBX[2]-5.
